Non-Normative Implementer Feedback Offered to Editor & WG

Wire, Stack & Consensus Precision

  • JS vs Python LEB128 Split-Brain: 0xe9b6ba808008 shifts mod 32 in JS to real Block 957,289 while Python/Rust read 274.8B. Fix: canonical ≤ 5-byte u32 LEB128.
  • Recursive WASM Stack Guard: 4,096-op linear proof triggers Python RecursionError and overflows 1 MB WASM stacks. Fix: iterative work-stack + depth cap.
  • Step 8/9 Ordering & SetCompact: Filter k ≥ 6 before argmin(b.H); reject negative nBits = 0x1dfbffff; select highest 256-bit ChainWork.

Appendix D.5 MTP & SCITT Header 394

  • Appendix D.5 122s MTP Offset: Draft prints 09:26:48Z (inclusive 957279..957289); exact BIP-113 median(H-11..H-1) is 09:24:46Z.
  • Zero-Wait Forward-MTP(H+5): Optional median(nTime[H-5..H+5]) at exact 6 confirmations gives consensus non-decreasing (≥) bounds.
  • SCITT Receipt Relay (RFC 9942): Appending receipts to unprotected header 394 breaks outer SHA-256(COSE_Sign1); bind deterministic Sig_structure (RFC 9921).
